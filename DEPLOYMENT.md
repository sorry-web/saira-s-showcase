# Vercel deployment

Import this repository in Vercel. Use the included settings: `bun install` and `bun run build`. Do not set an Output Directory override: Nitro creates Vercel's Build Output API directory automatically. Vercel sets `VERCEL=1`, selecting the Vercel preset without changing Lovable's target.

All four generated illustrative photographs are imported directly from `src/assets`. Vite includes them as hashed static files in the deployment. No Unsplash hotlinks, image API keys, image proxy, or remote domain allowlist are required. Do not omit `src/assets` when uploading the repository.

After deployment, check the opening image, both comparison images, leadership photograph, and each transition. A real Vercel deployment has not been performed or verified from this workspace.
